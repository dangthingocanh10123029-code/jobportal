# Resources — VibeCoding Job Portal

## Knowledge

- [Repository: `mattpocock/skills` — Matt Pocock](https://github.com/mattpocock/skills)
  Mã nguồn gốc và tài liệu đặc tả của hơn 30 kỹ năng dành cho AI Coding Agents. Dùng để: tra cứu cú pháp, frontmatter, và cơ chế router/subagent.
- [Book: _A Philosophy of Software Design_ — John Ousterhout](https://web.stanford.edu/~ouster/cgi-bin/book.php)
  Tác phẩm kinh điển về kiến trúc phần mềm, nguồn gốc của khái niệm Deep Modules (Interface nhỏ + Implementation sâu), Information Hiding và chống Shallow Modules. Dùng cho: `/codebase-design`.
- [Book: _Working Effectively with Legacy Code_ — Michael Feathers](https://www.oreilly.com/library/view/working-effectively-with/0131177052/)
  Khái niệm Seam (điểm may) và Seam Theory: cách thay đổi hành vi hoặc mock test mà không sửa đổi mã nguồn chính. Dùng cho: Seams & Adapters trong TypeScript.
- [Book: _Refactoring: Improving the Design of Existing Code_ — Martin Fowler](https://martinfowler.com/books/refactoring.html)
  Bảng phân loại Code Smells (Mysterious Name, Shotgun Surgery, Feature Envy, Primitive Obsession, Speculative Generality). Nguồn chuẩn mực cho trục Standards trong `/code-review`.
- [Official Documentation: Next.js App Router (nextjs.org)](https://nextjs.org/docs/app)
  Tài liệu chính thức về React Server Components, Server Actions, Route Handlers và kiến trúc tối ưu. Dùng cho: Xây dựng Backend & Frontend của VibeCoding Job Portal.
- [Official Documentation: Supabase (supabase.com/docs)](https://supabase.com/docs)
  Tài liệu chính thức về PostgreSQL database, Supabase Client JS, Row Level Security (RLS) và Database Functions/RPCs. Dùng cho: Lưu trữ dữ liệu và xử lý transactions.
- [Official Documentation: Vitest (vitest.dev)](https://vitest.dev/)
  Tài liệu chính thức về test runner hiện đại cho TypeScript/Vite/Next.js. Dùng cho: Vòng lặp TDD (Red-Green-Refactor).
